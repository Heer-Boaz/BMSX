# Manual fonts

Unmodified Liberation Sans and Liberation Mono TrueType fonts, version 2.1.5,
from the [upstream release](https://github.com/liberationfonts/liberation-fonts/releases/tag/2.1.5).
Copyright and SIL Open Font License 1.1 are in [LICENSE](LICENSE).

Archive: `liberation-fonts-ttf-2.1.5.tar.gz`

SHA-256: `7191c669bf38899f73a2094ed00f7b800553364f90e2637010a69c0e268f25d0`

Only the eight Sans/Mono faces and the license are vendored. The publisher embeds
these files unchanged in its HTML and uses them for prose, register diagrams,
and inline SVG lettering. Fonts are publication assets, not machine assets.
