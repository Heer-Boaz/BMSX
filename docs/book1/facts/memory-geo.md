# GEO addressed-buffer lifetime, bounded independent input

Internal source facts, 2026-10-17, no public prose. One unit: paired GEO controller/operation owners, paired contracts leaves and already frozen operation evidence. No architecture or reference PDF; no runtime edit. These facts do not establish GPU/PCRTC/APU/IMGDEC ownership or an allocator. TS raw u32 register words versus native u32 words; captured job contains addresses/counts/strides/parameters and counters, not source byte arrays.

- GB01: Accepted nonzero supported command copies SRC0/1/2,DST0/1,COUNT,PARAM0/1,STRIDE0/1/2 into job; source bytes are not read by this capture. Nonzero count then sets BUSY and schedules service. OVERLAP2D_PASS summary is a distinct launch-time write, BEFORE count test, not a source-copy edge. Sources TS `machine/ts/machine/devices/geometry/controller.ts:330-372`; native `machine/cpp/machine/devices/geometry/controller.cpp:225-265`; job raw field representation TS `machine/ts/machine/devices/geometry/job.ts:1-18`, native `machine/cpp/machine/devices/geometry/job.h:7-24`.
- GB02: XFORM2_BATCH reads the record during processRecord. A valid flags=0 record with vertexCount=0 succeeds immediately without reading a matrix or vertices. For a nonempty record that passes its range/shape checks, the selected matrix is read during that record and each local vertex immediately before corresponding output x/y writes; no whole-input snapshot/overlap branch. Destination vertices/AABB require RAM ranges. Sources TS `machine/ts/machine/devices/geometry/xform2.ts:42-108`; native `machine/cpp/machine/devices/geometry/xform2.cpp:18-83`. This sheet does not approve arbitrary in-place transforms or all alias arrangements. Derived hazard: changing record/matrix/vertex bytes after CMD can change pending work; use unchanged inputs and separate outputs until terminal state.
- GB03: SAT2 reads pair/descriptor/vertex words in processRecord; OVERLAP2D_PASS reads candidate/instance/shape/vertices in processRecord and its downstream operation, not at controller register capture. Sources TS `machine/ts/machine/devices/geometry/sat2.ts:57-120,150-163,211-216`, `overlap2d.ts:129-153,192-204,238-243,585-587`; native `machine/cpp/machine/devices/geometry/sat2.cpp:26-105,120-129,179-184`, `overlap2d.cpp:21-45,84-95,128-133,480-482`. Only delayed/live-read conclusion, not a new field-layout contract or malformed-input guarantee.
- GB04: Controller processes records during service, increments PROCESSED after a successful record, ends success when count reached. Success cancels service, discards active job, latches DONE/no fault then raises DONE IRQ. Execution fault cancels service/discards job, leaves completed-record count, latches DONE|ERROR and packed fault, raises ERROR IRQ. Sources TS `machine/ts/machine/devices/geometry/controller.ts:190-234,390-421`; native `machine/cpp/machine/devices/geometry/controller.cpp:178-220,300-331`; bit constants TS `machine/ts/machine/devices/geometry/contracts.ts:1-5`, native `machine/cpp/machine/devices/geometry/contracts.h:8-12`. Do not treat DONE alone as successful whole-batch output; check ERROR/FAULT/PROCESSED. Distinct unit/chapter IRQ acknowledgement still needed.
- GB05: No rollback is performed by the GEO controller fault path; operation writes already issued remain. XFORM record validation occurs before its output writes, but do not generalize to atomic whole job or every overlap record/summary. Sources GB02/GB04 plus exact overlap result/summary publication TS `machine/ts/machine/devices/geometry/overlap2d.ts:137-142,319-330,612-621`; native `machine/cpp/machine/devices/geometry/overlap2d.cpp:29-34,211-221,519-527`. Derived conservative ordinary-programming sequence: prepare all descriptors/data/outputs first; start command; leave inputs/outputs unmodified until operation stops; then distinguish completed result from retained partial writes before reusing buffers. Not a new access-protection mechanism or generic bus barrier.

Existing full operation layouts/programs remain GEO chapter, not reprinted/copied here. No new operation example or executed result from this bounded extract. Addresses use actual linked buffers; neither GEO scratch reservation nor unused mapped RAM is granted to a cart.

- GB06: Canonical complete command names/words are XFORM2_BATCH=0x20, SAT2_BATCH=0x21 and OVERLAP2D_PASS=0x22. Sources paired contracts TS `machine/ts/machine/devices/geometry/contracts.ts:22-24`, native `machine/cpp/machine/devices/geometry/contracts.h:29-31`. Use these names rather than undeclared OVERLAP.
- GB07: Read STATUS and program a nonbusy unit. A CMD write in BUSY does not wait/queue: it discards the running job, publishes REJECTED/zero PROCESSED/packed REJECT_BUSY and raises ERROR, without launching the new job. ERROR/REJECTED suppress later commands until local fault ACK; any nonzero local FAULT_ACK clears ERROR/REJECTED/FAULT but preserves DONE/BUSY/PROCESSED and does not resume discarded work. Sources TS `machine/ts/machine/devices/geometry/controller.ts:134-151,316-328,424-437`; native `machine/cpp/machine/devices/geometry/controller.cpp:168-176,268-285,334-346`. No arbitrary concurrent producer/isolation or successful recovery guarantee is implied.
