- A04. validateCallArity compares call.arguments.length (written expression count) with metadata.required. At least the required count returns without this diagnostic; fewer emits severity error with `${label} expects ${required} argument[s], but ${actualCount} was/were provided.` Thus an explicit nil expression counts as one written argument. This is a source diagnostic, not a fault thrown by a reached guest call, and no maximum count is checked here. Source toolchain/ts/lua/semantic/diagnostics.ts:395-418. No inference that this is an exhaustive SDK quality policy.
