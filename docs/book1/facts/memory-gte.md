# GTE PLUS operands are register words, not a RAM buffer

Internal bounded facts, 2026-10-17. Paired GTE live owners; mirrored PLUS constants are declared by these own files, not an invented separate spec leaf. No architecture/PDF, runtime edit, new measured result or full GTE re-extraction.

GT01: The ten PLUS words are ADD_XY,ADD_Z,MUL_XY,MUL_Z,SCALAR,RESULT_XY,RESULT_Z,FLAG,COMMAND,CYCLES at indices0..9. This is an operand/result register bank, not a source-address/length interface for a main-RAM buffer. Sources TS `machine/ts/machine/devices/gx/gte.ts:20-32`; native `machine/cpp/machine/devices/gx/gte.h:17-29`. No conversion of ordinary tables to addressed arrays implied.

GT02: An accepted supported VMAD3 COMMAND computes pending XY/Z/FLAG from the current operand words; writes to the five operand words ADD_XY through SCALAR (indices0–4) continue to replace their addressed operand word even while completion is pending. This statement excludes RESULT_XY, RESULT_Z, FLAG and CYCLES, which have no such write callback bound. Pending results publish together at completion and BUSY clears then. Thus changing operand registers after acceptance prepares words, not modification of that pending result; reading before completion does not acquire a newly completed result. Sources TS `machine/ts/machine/devices/gx/gte.ts:307-327,353-369,391-417`; native `machine/cpp/machine/devices/gx/gte.cpp:165-182,219-237,256-282`; callback binding TS `machine/ts/machine/devices/gx/gte.ts:215-222`, native `machine/cpp/machine/devices/gx/gte.cpp:78-85`. No guessed cycle delay/barrier or automatic resubmission.

GT03: PLUS COMMAND write-ready returns false for DMA, always; for CPU it synchronizes completion and accepts only when no command pending, otherwise schedules the interlock and returns not-ready. The busy write callback itself returns without starting another job. Sources TS `machine/ts/machine/devices/gx/gte.ts:358-388`; native `machine/cpp/machine/devices/gx/gte.cpp:225-253`. Use CPU command submission as already taught by full GTE chapter, not forced DMA acceptance. No GPU/DMA source-buffer reuse claim.

Subsequent correction/source check: GT02 now explicitly restricts pending writes to the five operand words, as independently required in `/tmp/bmsx-memory-gte-lifetime-source-review.md`.
