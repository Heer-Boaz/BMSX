# GPU shared-edge / joint output facts

Scope: only `gpu-shared-edges` and adjacent small-area claims were read in the manuscript. Actual mirrored GP0 specs, command decoder, software command/raster/VRAM owners and render rules were checked. No scoped disagreement found. No program, test, capture or execution was performed. Every numerical result below is a SOURCE-MATH DERIVATION, not an observed output.

## Owning rules

F01. GP0 polygon family is 20H–3FH; line family is 40H–5FH; bit 3 selects quad/polyline and bit 4 selects Gouraud. Sources: `machine/ts/spec/gx/gp0.ts:11–25`; `machine/cpp/spec/gx/gp0.h:18–32`.
F02. Opcode bit 1 enables semitransparency; bit 2 enables texture; bit 3 selects quad; bit 4 selects Gouraud. Thus 2AH is flat, untextured, semitransparent quad; 4AH is flat semitransparent polyline. Sources: `machine/ts/render/backend/gx_gpu_render_rules.ts:83–96`; `machine/cpp/render/backend/gx_gpu_render_rules.h:75–88`.
F03. A flat untextured quad has five words: color/opcode followed by four XY words; triangles execute (0,1,2) then (2,1,3), carrying the same color. Sources: `machine/ts/render/backend/software/gx_gpu_commands.ts:201–208`; `machine/cpp/render/backend/software/gx_gpu_commands.cpp:203–210`.
F04. Polygon packet length confirms five words for 2AH. Flat line/polyline initial packet length is three words. Sources: `machine/ts/machine/devices/gx/gpu.ts:1745–1756`; `machine/cpp/machine/devices/gx/gpu.cpp:1228–1239`.
F05. XY words pack X in low 16 and Y in high 16; vertex X/Y decode signed low eleven bits. Sources: `machine/ts/spec/gx/gp0.ts:62–68`, `machine/ts/render/backend/gx_gpu_render_rules.ts:71–76`; mirrors: `machine/cpp/spec/gx/gp0.h:64–70`, `machine/cpp/render/backend/gx_gpu_render_rules.h:63–68`.
F06. Triangle edge value is (X−ax)(by−ay)−(Y−ay)(bx−ax); zero area returns without writes. Bounds intersect drawing area and exclude maximum X/Y; negative area flips the edge sign. Sources: `machine/ts/render/backend/software/gx_gpu_rasterizer.ts:53–54,223–259`; `machine/cpp/render/backend/software/gx_gpu_rasterizer.cpp:45–46,225–261`.
F07. For edge steps stepX=s(by−ay), stepY=−s(bx−ax), coverage minimum is zero iff stepX>0 or (stepX=0 and stepY>0), otherwise one; all three edge intervals must intersect. Sources: `machine/ts/render/backend/gx_gpu_render_rules.ts:288–289`, `machine/ts/render/backend/software/gx_gpu_rasterizer.ts:279–288,325–347`; mirrors: `machine/cpp/render/backend/gx_gpu_render_rules.h:292–293`, `machine/cpp/render/backend/software/gx_gpu_rasterizer.cpp:271–280,313–339`.
F08. Draw-mode blend selection is bits 6:5; selection 1 is background plus foreground. Dither enable is bit 9; draw-to-displayed-field is bit 10. Sources: `machine/ts/spec/gx/gp0.ts:44–55`, `machine/ts/render/backend/gx_gpu_render_rules.ts:311–312`; mirrors: `machine/cpp/spec/gx/gp0.h:46–57`, `machine/cpp/render/backend/gx_gpu_render_rules.h:315–316`.
F09. Setting draw-to-displayed-field makes the row-suppression predicate false, independently of the resolution/interlace bits. Sources: `machine/ts/machine/devices/gx/gpu.ts:194–195,2002–2005`; `machine/cpp/machine/devices/gx/gpu.cpp:26–27,1476–1479`.
F10. Flat untextured polygon output does not enable dither even if its mode bit is set; line output uses that bit directly. The chosen E1 word below clears it for both. Sources: `machine/ts/render/backend/gx_gpu_render_rules.ts:292–296`, `machine/ts/render/backend/software/gx_gpu_rasterizer.ts:700–702`; mirrors: `machine/cpp/render/backend/gx_gpu_render_rules.h:296–300`, `machine/cpp/render/backend/software/gx_gpu_rasterizer.cpp:859–861`.
F11. E6 bit 0 forces stored bit 15; bit 1 rejects a destination with bit 15 already set. Untextured output supplies zero source mask, so E6=0 stores bit 15 clear. Sources: `machine/ts/render/backend/gx_gpu_render_rules.ts:337–342`, `machine/ts/render/backend/software/gx_gpu_vram.ts:115–139`; mirrors: `machine/cpp/render/backend/gx_gpu_render_rules.h:341–346`, `machine/cpp/render/backend/software/gx_gpu_vram.h:100–122,186–198`.
F12. Untextured RGB bytes become five-bit channels by right shift three before blending. Additive mode adds per channel with saturation at 31; the final color is masked to 7FFFH. Sources: `machine/ts/render/backend/software/gx_gpu_vram.ts:47–81,129–139`; `machine/cpp/render/backend/software/gx_gpu_vram.h:64–97,174–198`.
F13. E3/E4 drawing endpoints decode X bits 9:0 and Y above bit 9; E4 right/bottom become exclusive by adding one when ordered. Sources: `machine/ts/spec/gx/gp0.ts:71–92`; `machine/cpp/spec/gx/gp0.h:73–94`.
F14. Accepted E1/E2/E3/E4/E5/E6 commands update their programmed environment; each later emitted command captures the current words and skipped parity. Sources: `machine/ts/machine/devices/gx/gpu.ts:1212–1233,1770–1784`; `machine/cpp/machine/devices/gx/gpu.cpp:791–813,1253–1266`.
F15. A fill writes quantized color directly, bypassing drawing-area, offset and mask/blend paths, but obeying skipped parity. Fill X is aligned down to 16 and width rounded up to 16. Sources: `machine/ts/render/backend/software/gx_gpu_commands.ts:53–72`, `machine/ts/render/backend/gx_gpu_render_rules.ts:125–134`; mirrors: `machine/cpp/render/backend/software/gx_gpu_commands.cpp:11–36`, `machine/cpp/render/backend/gx_gpu_render_rules.h:117–126`.
F16. Flat polyline continuation emits a new line from the retained previous endpoint to the next XY word; the initial packet draws its first segment. A following word matching (word AND F000F000H)=50005000H terminates at phase zero and is not a vertex. Sources: `machine/ts/machine/devices/gx/gpu.ts:1161–1175,1702–1718`; `machine/cpp/machine/devices/gx/gpu.cpp:729–743,1179–1195`.
F17. Each accepted unclipped line uses max(abs(dx),abs(dy)) steps and loops through step<=steps, so both endpoints participate. Flat horizontal positive-X segments produce every integer X once. Sources: `machine/ts/render/backend/software/gx_gpu_rasterizer.ts:77–98,684–749`; `machine/cpp/render/backend/software/gx_gpu_rasterizer.cpp:14–30,843–907`.
F18. Raw RGB555 storage index is Y×1024+X here; X wraps at 1024. The proposed screen scene fits X<256,Y<192 so does not reach a wrap edge. Sources: `machine/ts/render/backend/software/gx_gpu_vram.ts:11–12`, `machine/ts/spec/gx/vram.ts:1–12`; mirrors: `machine/cpp/render/backend/software/gx_gpu_vram.h:16–24`, `machine/cpp/spec/gx/vram.h:9–21`.
