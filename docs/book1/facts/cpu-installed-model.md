## Scope/claim boundary

Supported manual wording: the installed model configuration uses a 33,868,800 Hz CPU rate and 4 MiB of RAM. This rate is the model's timing/accounting input, not a measured physical processor speed or a promise that one instruction always consumes one clock. The 4 MiB figure is the installed RAM allocation, not the maximum architectural RAM address window.

RuntimeOptions requires an explicit machineModel (`machine/ts/machine/runtime/options.ts:4-8`; `machine/cpp/machine/runtime/options.h:13-17`). Custom callers can supply another model. Runtime timing can later be changed through setFrameTiming (`machine/ts/machine/runtime/timing/config.ts:18-25`; `machine/cpp/machine/runtime/timing/config.cpp:22-28`). No universal-all-target/default-omission fallback or immutable-frequency assertion is established. Other host products were not enumerated; the common model's actual selection is proven for the two named production paths above.
