# Narrow installed BIOS table globals: frozen facts

2026-10-17 baseline5a5a26e15. Source facts only, no whole builtin reference claim.

- TB01. Installed BIOS aliases the boot primitives to public `setmetatable`, `getmetatable`, `rawget`, `rawset`. Source `machine/bios/base.lua:4-7,207-210`. Boot identity mapping is paired at `machine/ts/spec/blua32/builtin.ts:43-46` and `machine/cpp/spec/blua32/builtin.h:52-55`.
- TB02. `setmetatable(t, mt)` requires a Table first argument. A Table second argument becomes t's metatable; nil or an omitted second argument clears it; any other second argument faults INVALID_ARGUMENT. Returns t itself. Sources `machine/ts/machine/cpu/cpu.ts:4198-4216`; `machine/cpp/machine/cpu/cpu.cpp:2107-2122`. Missing native arguments supply nil from `machine/cpp/machine/cpu/value.h:343`. Paired agrees.
- TB03. `getmetatable(t)` requires a Table and returns its actual metatable Table, or nil if none. Sources `machine/ts/machine/cpu/cpu.ts:4218-4228`; `machine/cpp/machine/cpu/cpu.cpp:2124-2132`. No protected-metatable substitution in these leaves. Paired agrees.
- TB04. `rawget(t, key)` requires Table t and directly loads its own mapping, ignoring the metatable. Missing or explicit nil key reaches Table nil-key fault INDEX_NIL. Missing admissible key returns nil. Sources `machine/ts/machine/cpu/cpu.ts:4230-4248`; `machine/cpp/machine/cpu/cpu.cpp:2134-2142`; native absent argument `value.h:343`; Table direct/nil semantics in supplied Table fact sheet. Paired agrees.
- TB05. `rawset(t, key, value)` requires Table t, directly stores the mapping and returns t. Omitted value means nil/deletion. Omitted or nil key faults INDEX_NIL, including deletion. Sources `machine/ts/machine/cpu/cpu.ts:4250-4283`; `machine/cpp/machine/cpu/cpu.cpp:2144-2152`; native absent argument `value.h:343`; Table store/nil semantics in supplied Table facts. Paired agrees except stopped general length-refill producer transition already recorded separately; do not imply rawset fixes it.
- TB06. Fault codes INDEX_NIL=4, METATABLE_LOOP=5, INVALID_ARGUMENT=10. Sources `machine/ts/spec/blua32/cop0.ts:30-31,36`; `machine/cpp/spec/blua32/cop0.h:36-37,42`.

These are the actual BIOS globals, not a requirement for a wrapper or fictitious control array. No pcall, iteration, complete metamethod, GC or string interning contract extracted here.
