# DMA reader-orientation facts — current mirrored owners

Scope: first chapter/table used only as locators; actual scoped owners/spec inspected. No architecture document/reference PDF opened. No scoped TS/C++ disagreement found. This is evidence for later authoring, not replacement prose.

- F01 — Two programmable channels, numbered 0 and 1; each has READ_ADDR, WRITE_ADDR, TRANSFER_COUNT, CONTROL, STATUS and TRIGGER. Sources: `machine/ts/spec/bmsx/io.ts:10-18,131-137`; `machine/cpp/spec/bmsx/io.h:22-30,144-150`.
- F02 — The two channels have the same programmed capabilities: independently chosen addresses, count, read/write increments, request selectors and 1–16-word block length. The same channel-indexed admission/service logic applies to both; neither is dedicated to GPU or APU. Sources: `machine/ts/machine/devices/dma/controller.ts:211-235,394-419,487-491`; `machine/cpp/machine/devices/dma/controller.cpp:141-165,318-343,412-416`.
- F03 — The banks occupy different addresses and completion raises a different IRQ source for each channel; equivalence does not mean identical register/IRQ identity. Sources: `machine/ts/spec/bmsx/io.ts:219-237`; `machine/ts/machine/devices/dma/controller.ts:365-370`; `machine/cpp/spec/bmsx/io.h:232-250`; `machine/cpp/machine/devices/dma/controller.cpp:289-294`.
- F04 — Both channels can retain BUSY simultaneously: START rejects only when its selected channel is already BUSY, and sets that channel BUSY before arbitration. Sources: `machine/ts/machine/devices/dma/controller.ts:131-143`; `machine/cpp/machine/devices/dma/controller.cpp:62-73`.
- F05 — Their transfer path is shared: only one admitted block exists across both channels; arbitration returns while that block/service is active. Thus simultaneous BUSY is not simultaneous block transfer. Sources: `machine/ts/machine/devices/dma/controller.ts:69-79,386-408,463-470`; `machine/cpp/machine/devices/dma/controller.cpp:310-332,387-394`.
- F06 — At each admission search the next-channel cursor is examined first; after an admission it moves to the other channel. A non-BUSY/ineligible channel is skipped. This is block-level rotating priority, not a permanently higher-priority channel. Sources: `machine/ts/machine/devices/dma/controller.ts:394-407`; `machine/cpp/machine/devices/dma/controller.cpp:318-331`.
- F07 — Read and write request selectors are independent; both must assert for admission. Choosing APU/GX requests does not rewrite either programmed endpoint. Sources: `machine/ts/machine/devices/dma/controller.ts:412-423,487-501`; `machine/cpp/machine/devices/dma/controller.cpp:336-347,412-426`.
- F08 — The APU has a separate FIFO-to/from-sample-RAM transfer datapath: DMA writes fill its FIFO, DMA reads drain it, and the APU's own completed batches move words between that FIFO and sample RAM. It is not a third programmable DMA channel. Sources: `machine/ts/machine/devices/audio/sample_transfer.ts:159-179,201-236`; `machine/cpp/machine/devices/audio/sample_transfer.cpp:122-150,195-235`; two-channel limit: F01.
- F09 — APU DMA-write readiness means its FIFO is empty; DMA-read readiness means full. These APU-generated request lines gate the programmable channels. Manual-write mode instead stores each CPU data word directly into sample RAM. Sources: `machine/ts/machine/devices/audio/sample_transfer.ts:151-155,261-265`; `machine/cpp/machine/devices/audio/sample_transfer.cpp:134-138,244-248`.
- F10 — Installed DMA timing: RAM costs N+1 system cycles for an N-word region span including its setup; system ROM costs N; cartridge ROM costs 8N+4 including its setup; I/O adds zero endpoint cost in this DMA transport model. Sources: `machine/ts/spec/bmsx/model.ts:7-12,46-52`; `machine/ts/machine/devices/dma/controller.ts:473-483`; `machine/cpp/spec/bmsx/model.h:12-17,51-57`; `machine/cpp/machine/devices/dma/controller.cpp:397-407`.
- F11 — Same-region RAM→RAM charges read+write; different endpoint regions charge the larger of their two span costs. Sources: `machine/ts/machine/devices/dma/controller.ts:434-441`; `machine/cpp/machine/devices/dma/controller.cpp:358-365`.
- F12 — Derived admission-to-service costs for one uninterrupted N-word block wholly within its endpoint regions: RAM→RAM=2(N+1); cartridge-ROM→RAM=8N+4; system-ROM→RAM=N+1. Therefore “ROM is slower than RAM” is too broad: distinguish cartridge ROM from system ROM. Derivation: F10–F11.
- F13 — Fixed-GP0 transport costs under the same conditions: RAM→GP0=N+1; cartridge-ROM→GP0=8N+4; system-ROM→GP0=N. GP0 is an I/O endpoint and DMA writes enter GPU command ingress; these are not direct-VRAM-aperture bandwidths. Sources: cost F10–F11; `machine/ts/machine/memory/memory.ts:725-735`; `machine/ts/machine/devices/gx/gpu.ts:462-464,1034-1052`; `machine/cpp/machine/memory/memory.cpp:642-652`; `machine/cpp/machine/devices/gx/gpu.cpp:53-55,551-569`.
- F14 — Those costs exclude request-gate waiting and GPU command execution after transport; they are neither electrical ratings nor an unconditional end-to-end rendering rate. Request admission: F07. Separate ingress/execution: F13. The source deadline is anchorCycle+blockCycles: `machine/ts/machine/devices/dma/controller.ts:469-470`; `machine/cpp/machine/devices/dma/controller.cpp:393-394`.

Editorial consequence: explain two equally programmable channels sharing one transfer engine, the APU boundary, and cartridge-ROM versus RAM cost before giving the quantitative resource/register inventory. Do not replace “Installed resources” with another inventory heading and call that reader orientation. Do not write an unqualified “parallel” claim.
