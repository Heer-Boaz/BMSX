# BLua text and byte storage: bounded facts

2026-10-17, HEAD b582b7344. Internal author input, not public prose. Only the named string, scalar-load, literal/constant and installed library producers were inspected. No architecture document/reference PDF or runtime edits. Paired assertions below concern ordinary produced strings and valid Unicode scalar text, not corrupt image encodings. No full string library, memory allocator, complete language-fault/recovery, or generic encoding API is inferred.

- **MS01 — Logical text is distinct from a mapped byte span.** String values select interned text. They are not numeric byte addresses. The compiler's static `string` field stores a four-byte constant index in RODATA, and typed loading reads U32LE then LOADKR; a raw address of that field is the index's location, not the characters' byte address. Existing BS10 is confirmed by `toolchain/ts/lua/compiler.ts:3788-3798,5181-5189`. String pool intern/toString owner `machine/ts/machine/cpu/string_pool.ts:27-59,126-132`; native `machine/cpp/machine/cpu/string_pool.cpp:32-80,138-145`.
- **MS02 — Length counts codepoints.** On a string, LEN publishes its codepoint count; `string.len(value)` returns `#value`. It does not return UTF-8 byte count. TS `machine/ts/machine/cpu/cpu.ts:2672-2678`, pool `string_pool.ts:126-129`, counter `machine/ts/common/utf8.ts:1-7`; native `machine/cpp/machine/cpu/cpu_dispatch.inl:319-324`, pool `string_pool.cpp:138-145`, counter `machine/cpp/common/utf8.h:27-53`; library `machine/bios/string/base.lua:43-45`. The counters traverse zero codepoint as an ordinary character, not a terminator.
- **MS03 — `string.byte(s, i)` selects one codepoint, not an encoded byte or range.** Library binds byte to the primitive. Source must be string. Position defaults to1 when omitted/nil; a supplied non-nil position must be numeric and is converted to signed32. Positions below1 and beyond the string return nil. It walks codepoints from1, emits one numeric scalar at the selected position and returns; an extra range-end argument is not read by this primitive. TS `machine/ts/machine/cpu/cpu.ts:4320-4351`; native `machine/cpp/machine/cpu/cpu.cpp:2176-2207`; binding `machine/bios/string/base.lua:1,39`. Do not import negative-from-end or multi-byte/range return rules from another language.
- **MS04 — `string.char(...)` constructs text from scalar values.** Each argument must be numeric. Each is converted to unsigned32, then values above10FFFFH or within D800H..DFFFH raise INVALID_ARGUMENT; accepted values append a Unicode scalar. Zero is accepted. No arguments produces empty text. It is not limited to0..255. TS `machine/ts/machine/cpu/cpu.ts:4353-4371`; native `machine/cpp/machine/cpu/cpu.cpp:2209-2223`, UTF8 append `machine/cpp/common/utf8.h:98-119`; binding `machine/bios/string/base.lua:2,40`. Paired reason INVALID_ARGUMENT=10: `machine/ts/spec/blua32/cop0.ts:36`, native `machine/cpp/spec/blua32/cop0.h:42`. This is a language argument error, not an inferred Memory fault/IRQ or repair policy.
- **MS05 — Existing address-to-text bridge is `string.from_utf8(address, byte_count)`.** `string/base` exposes `string/utf8.decode`. It binds the address as `*u8`, computes finish=source+byte_count, reads sequential leading/continuation bytes, combines1/2/3/4-byte sequences into codepoints, and constructs text with the existing char/table facilities. A zero byte becomes scalar0; it does not stop decoding. `machine/bios/string/base.lua:7`; full sole producer `machine/bios/string/utf8.lua:1-58`. This is a byte count, not a codepoint count or a pointer to a static string-constant field.
- **MS06 — Bridge input discipline (DERIVED from exact reads).** Supply a backed span containing complete well-formed UTF-8 sequences. The helper checks only source<finish before the next lead; continuation accesses do not compare their positions with finish, validate continuation prefixes or reject overlong encodings. A count ending inside a sequence does not make those later reads stop at finish. Do not promise bounded validation, zero termination, safe truncated/malformed decoding or automatic resource ownership. `machine/bios/string/utf8.lua:14-35,43-53`; downstream char acceptance MS04. No malformed-input mirror claim is authored.
- **MS07 — Installed library route.** Boot sets `string = require('string')`; that module returns `string/base` after adding pattern/format/pack operations. `machine/bios/main.lua:4-12`; `machine/bios/string.lua:1-22`; `machine/bios/string/base.lua:1-7,39-45`. These logical string-table operations are not one of the three direct linked BIOS imports: current direct export list is math/sin, string/float/decode, gpu/system_vram_region, `toolchain/ts/rompack/system.ts:9-21`. Cart visibility is ordinary shared global lookup, not GETSYS: non-boot names select GETGL/SETGL, and paired name registration maps equal interned names to the same persistent non-system slot across images. Sources `toolchain/ts/lua/compiler/system_boot_symbols.ts:5-10`, `toolchain/ts/lua/compiler.ts:591-600,2827-2828,2885-2886`; paired `machine/ts/machine/cpu/cpu.ts:1013-1045,1106-1124,1334-1342,2351-2357` / `machine/cpp/machine/cpu/cpu.cpp:561-591,631-641,922-930`, native dispatch `machine/cpp/machine/cpu/cpu_dispatch.inl:70-77`. DERIVED caution: do not overwrite the shared string global/library table while other users require it; library visibility is not private per-cartridge library storage.
- **MS08 — Literal escape values are characters, not a UTF-8 decoding request.** The lexer reads `\x` plus exactly2hex digits into that character value; decimal escape reads up to3digits and accepts0..255. `toolchain/ts/lua/syntax/lexer.ts:338-381`. The linker UTF-8-encodes source string text into image string records: `toolchain/ts/rompack/blua32_linker.ts:179,759-770`. Ordinary compiled valid text is loaded through paired constant-string paths `machine/ts/machine/cpu/cpu.ts:930-948,995-1001` / native `machine/cpp/machine/cpu/cpu.cpp:484-505,539-548`. DERIVED example: literal `\xc3\xa9` is two codepoints C3H,A9H, not one E9H; actual mapped UTF-8 bytes C3H,A9H passed through MS05 produce E9H. Exact executed example remains separate evidence.
- **MS09 — Numeric pack output is still a string value.** Existing numeric pack loop emits `char(value %256)` per logical byte, then concat returns text; unpack reads `byte(source,index)` for numeric reconstruction. `machine/bios/string/pack.lua:87-100,114-129,277-306,336,399-406`; installed binding `machine/bios/string.lua:15-18`. This does not supply a CPU address, DMA source pointer or raw text-encoding operation. Full format/endian/size/error reference is outside this extract; do not teach arbitrary non-byte-valued strings as binary pack input from this row.
