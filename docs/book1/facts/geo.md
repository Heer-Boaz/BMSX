Book I installed geometry batch unit. This is editorial source evidence, not
public chapter prose. The live software contract is authoritative for this
edition; no architecture document or reference PDF supplied facts. GCR covers
the controller/register/timing boundary, GXF/GSA the two fixed-point units, GOV
the floating-point overlap unit, and GBL the real source-language precedents.
Internal state is not an additional cartridge interface.

The three scoped hardware extractions are paired independently. They report no
confirmed mismatch in their inspected paths; their explicit scope limits must
not be silently expanded to all malformed geometry, aliasing or all possible
bit patterns. Undefined electrical ratings and separately unestablished
malformed-geometry behavior are not replaced by invented safe fallbacks.

## Cartridge-visible words

GCR-01 Address derivation: 32-bit address space; IO_BASE=RAM_BASE=0x08000000; IO_WORD_SIZE=4; GEO begins at IO word index 9; the contiguous bank has 16 words/64 bytes. Numeric addresses below are direct evaluation of the paired constants. Sources: `machine/ts/spec/bmsx/memory_map.ts:1-7,23-33`, `machine/ts/spec/bmsx/io.ts:3-37,239-274`; `machine/cpp/spec/bmsx/memory_map.h:7-13,29-39`, `machine/cpp/spec/bmsx/io.h:15-49,252-287`.

GCR-02 Register inventory. All bank words reset to 0. RW means cartridge mapped aligned-word writes accepted and raw stored bits read back; RO means mapped writes are rejected by the memory owner. Register-specific changes are below.

GCR-03 Readback/write path: GEO installs write callbacks, no read callbacks. Memory mapped-write stores the raw u32 IO backing word before invoking the GEO callback. Configuration writes copy that word to GEO's register array, without masking or decoding. CMD likewise stores the written whole value before doorbell handling, including a command subsequently ignored by sticky fault state. CTRL stores the whole word, then clears ABORT bit if set. No unspecified bits are described as read-as-zero. Sources: `machine/ts/machine/devices/geometry/controller.ts:104-132,297-304`, `machine/ts/machine/memory/memory.ts:366-376,627-642`; `machine/cpp/machine/devices/geometry/controller.cpp:49-79,152-159`, `machine/cpp/machine/memory/memory.cpp:245-259,522-535`.

GCR-04 Mapped access policy is distinct from GEO's direct memory datapath. Mapped writes to STATUS/PROCESSED/FAULT produce the general memory READ_ONLY bus fault and return without writing. Unaligned mapped IO word accesses fault; mapped IO byte/halfword writes fault. Direct `readU32`/`writeU32` use main-memory backing and do not invoke GEO/MMIO callbacks. `isReadableMainMemoryRange` and `isRamRange` accept installed RAM, including the IO address aperture's RAM backing; do NOT claim these helpers exclude the IO aperture. Sources: `machine/ts/machine/memory/memory.ts:392-411,466-479,486-505,591-616,627-656,697-705,721-723,840-845,852-873`; `machine/cpp/machine/memory/memory.cpp:280-299,356-369,376-395,486-511,522-550,611-620,636-639,729-750`. This distinguishes MMIO register policy from direct output-memory behavior.

## Commands, acceptance, latches, and results

GCR-05 Supported complete CMD words: XFORM2_BATCH=0x20, SAT2_BATCH=0x21, OVERLAP2D_PASS=0x22. Controller launch checks only membership in this list, not pointers, strides, parameters, payload alignment, record flags, or payload shape. Unknown complete words reject even when COUNT=0. Source: `machine/ts/machine/devices/geometry/contracts.ts:21-23`, `machine/ts/machine/devices/geometry/controller.ts:330-364`; `machine/cpp/machine/devices/geometry/contracts.h:29-31`, `machine/cpp/machine/devices/geometry/controller.cpp:225-257`.

GCR-06 CMD acceptance by internal phase: IDLE or DONE starts; ERROR or REJECTED ignores doorbell effects until local fault ACK (but CMD raw readback already changed); BUSY triggers REJECT_BUSY and terminates/discards the active job rather than queueing or preserving it. There is exactly one optional active job and no command FIFO in this controller. Sources: `machine/ts/machine/devices/geometry/controller.ts:84-85,316-328,424-436`; `machine/cpp/machine/devices/geometry/controller.h:66-69`, `machine/cpp/machine/devices/geometry/controller.cpp:168-177,334-345`.

GCR-07 Launch captures cmd, src0/src1/src2, dst0/dst1, count, param0/param1, stride0/stride1/stride2. Internal progress/resultCount/exactPairCount/broadphasePairCount initialize 0. Subsequent configuration writes change register readback/the next launch, not the active captured job. Payload bytes are not captured by the controller: on service it calls the selected unit's processRecord with captured job and current memory owner; per-unit record/payload reads occur there. Sources: `machine/ts/machine/devices/geometry/controller.ts:120-126,195-224,330-348,368-372`, `machine/ts/machine/devices/geometry/job.ts:1-18`; `machine/cpp/machine/devices/geometry/controller.cpp:65-73,184-211,225-238,259-265`, `machine/cpp/machine/devices/geometry/job.h:7-23`. Per-unit payload layouts/validation are separate unit facts, not guessed here.

GCR-08 After accepted opcode, launch clears STATUS, PROCESSED, FAULT. OVERLAP additionally writes four zero summary words at DST1+0,+4,+8,+12 through direct writeU32 before testing COUNT or entering BUSY; writeSummary returns void and performs no address/setup validation. COUNT=0 then completes immediately (DONE/IRQ_DONE), without unit processRecord validation. Nonzero COUNT resets budget carry/available units, installs captured job, sets STATUS=BUSY=1, and schedules service. Sources: `machine/ts/machine/devices/geometry/controller.ts:349-372,399-407`, `machine/ts/machine/devices/geometry/overlap2d.ts:137-142`; `machine/cpp/machine/devices/geometry/controller.cpp:239-265,309-317`, `machine/cpp/machine/devices/geometry/overlap2d.cpp:29-34`. Do not substitute a purported launch-time OVERLAP destination validation for the actual direct write side effect.

GCR-09 Each successful unit processRecord increments captured processed and cartridge PROCESSED by 1. Reaching COUNT completes: active job discarded, budget/carry zeroed, GEO service canceled, STATUS=2 (DONE only), PROCESSED=completed count, FAULT=0, IRQ_DONE raised. Unit fault return !=0 instead terminates with STATUS=6 (DONE|ERROR), FAULT packed with current job.processed (the failing outer-record index), active job/budget cleared/service canceled, IRQ_ERROR raised. PROCESSED is not incremented for the failing record and finishError leaves its existing value. Earlier memory outputs are not rolled back by the controller. Sources: `machine/ts/machine/devices/geometry/controller.ts:198-224,390-421`; `machine/cpp/machine/devices/geometry/controller.cpp:186-211,300-331`.

GCR-10 Rejection sets STATUS=8 (REJECTED only; no DONE), PROCESSED=0, FAULT=(reject code<<16)|0xffff, discards active job/carry/available work, cancels service, raises IRQ_ERROR. Thus BUSY rejection resets published PROCESSED even if previous records had completed; it does not undo memory writes. Source: `machine/ts/machine/devices/geometry/controller.ts:323-325,424-445`; `machine/cpp/machine/devices/geometry/controller.cpp:172-174,334-354`.

GCR-11 CTRL bit0 ABORT is self-clearing on every write containing it. In BUSY it terminates as ERROR/DONE with ABORTED code and current processed index; in IDLE/DONE it has no job/result effect; in ERROR/REJECTED it does not replace sticky fault. Non-ABORT bits remain as written; no IRQ-enable/reset/start CTRL bits are defined here. Sources: `machine/ts/machine/devices/geometry/contracts.ts:1-5`, `machine/ts/machine/devices/geometry/controller.ts:129-132,297-314`; `machine/cpp/machine/devices/geometry/contracts.h:8-12`, `machine/cpp/machine/devices/geometry/controller.cpp:76-79,152-166`.

GCR-12 First-fault stickiness is implemented by ERROR/REJECTED phase gating CMD and abort. A later CMD changes raw CMD readback but leaves the first fault/status/progress intact; ABORT self-clears its pulse but leaves fault intact. FAULT_ACK nonzero clears ERROR and REJECTED bits, clears FAULT, writes ACK readback 0; ERROR phase becomes DONE, REJECTED becomes IDLE. DONE/BUSY status bits and PROCESSED are preserved by ACK. Zero ACK returns without action. ACK does not call IRQ clear/ack and does not resume a discarded job. Sources: `machine/ts/machine/devices/geometry/controller.ts:124-150,297-325`; `machine/cpp/machine/devices/geometry/controller.cpp:70-79,152-174,268-283`.

GCR-13 FAULT encoding is `(code&0xffff)<<16 | (recordIndex&0xffff)`. The cartridge index field is low16 only, independently of full32 COUNT/PROCESSED; rejection index sentinel=0xffff. Defined codes: ABORTED 0x0001; BAD_RECORD_ALIGNMENT 0x0002; BAD_VERTEX_COUNT 0x0003; SRC_RANGE 0x0004; DST_RANGE 0x0005; DESCRIPTOR_KIND 0x0006; NUMERIC_OVERFLOW_INTERNAL 0x0007; BAD_RECORD_FLAGS 0x0008; RESULT_CAPACITY 0x0009; REJECT_BUSY 0x8001; REJECT_BAD_CMD 0x8002. Definition does not prove every code is emitted by every installed unit. Sources: `machine/ts/machine/devices/geometry/contracts.ts:141-156`, `machine/ts/machine/devices/geometry/controller.ts:77-79,416-433`; `machine/cpp/machine/devices/geometry/contracts.h:149-164`, `machine/cpp/machine/devices/geometry/controller.cpp:32-34,326-343`.

GCR-14 IRQ bits are GEO_DONE=1<<3=0x8 and GEO_ERROR=1<<4=0x10. Success raises DONE; execution fault/abort/rejection raises ERROR, not both. These are IRQ-controller raises, not status-bit aliases and not automatic local FAULT_ACK effects. Sources: `machine/ts/spec/bmsx/io.ts:365-366`, `machine/ts/machine/devices/geometry/controller.ts:399-436`; `machine/cpp/spec/bmsx/io.h:378-379`, `machine/cpp/machine/devices/geometry/controller.cpp:309-345`.

## Internal state, reset, supervisor, save state

GCR-15 Internal phase values IDLE=0 BUSY=1 DONE=2 ERROR=3 REJECTED=4 are not cartridge STATUS word encodings (STATUS values are 0/1/2/6/8 in normal transitions). Raw bank is Uint32Array(16) in TS / array<u32,16> in C++; job fields are number holding raw words in TS / uint32_t in C++. Carry/timing are internal TS numbers/C++int64; available work is internal number/uint32. Sources: `machine/ts/machine/devices/geometry/contracts.ts:7-19`, `machine/ts/machine/devices/geometry/controller.ts:83-94`, `machine/ts/machine/devices/geometry/job.ts:1-18`; `machine/cpp/machine/devices/geometry/contracts.h:14-27`, `machine/cpp/machine/devices/geometry/controller.h:62-75`, `machine/cpp/machine/devices/geometry/job.h:7-23`.

GCR-16 GEO reset enters IDLE, clears active job/carry/available work/quiesce request, cancels GEO service, zeroes/mirrors all16 words and separate ACK. setTiming's cpuHz/workUnitsPerSec are not reset here. GEO reset itself does not call IRQ reset; full Machine.resetDevices resets IRQ separately before GEO. Sources: `machine/ts/machine/devices/geometry/controller.ts:237-246`, `machine/ts/machine/machine.ts:108-119`; `machine/cpp/machine/devices/geometry/controller.cpp:125-134`, `machine/cpp/machine/machine.cpp:51-62`.

GCR-17 Supervisor quiesce sets a private request, makes CMD mapped-write-ready false, and schedules SYSTEM service at current scheduler cycle. It does not abort ongoing GEO; quiescent means phase!=BUSY. Completion/error/rejection notify SYSTEM again when quiesce requested. Leaving context clears request. The memory mapped-write-ready check is a backpressure boundary, not GEO's BUSY rejection rule. Sources: `machine/ts/machine/devices/geometry/controller.ts:110-118,278-295,399-436`, `machine/ts/machine/memory/memory.ts:261-265,635-639`; `machine/cpp/machine/devices/geometry/controller.cpp:55-62,137-150,309-345`, `machine/cpp/machine/devices/geometry/controller.h:37-39`, `machine/cpp/machine/memory/memory.cpp:181-185,529-533`.

GCR-18 Controller save captures phase, all16 raw words, optional captured job including its mutable counters, workCarry, availableWorkUnits, supervisorQuiesceRequested. It does not capture CPUHz/workUnitsPerSec or separate ACK in this controller structure. Restore copies words, forces CTRL ABORT clear, mirrors bank, restores phase/job/budget/quiesce, then reschedules against supplied nowCycles. No processing is replayed and no IRQ is raised by the controller restore method. Sources: `machine/ts/machine/devices/geometry/save_state.ts:4-11`, `machine/ts/machine/devices/geometry/controller.ts:249-275`; `machine/cpp/machine/devices/geometry/save_state.h:12-19`, `machine/cpp/machine/devices/geometry/save_state.cpp:7-27`.

## Installed capacities and cycle model

GCR-19 Installed PSX model: CPU=33,868,800Hz, GEO=16,384,000 work units/s; RAM=0x00400000=4MiB, GPU VRAM=0x00200000=2MiB (not GEO-private storage). Reserved GEO scratch definition: 0x00080000=512KiB at RAM_BASE+IO_REGION_SIZE=0x08040000; IO region=0x00040000=256KiB; DYNAMIC_RAM_BASE=0x080c0000. These are memory/model software-edition facts, not inferred physical chip ratings. Sources: `machine/ts/spec/bmsx/model.ts:7-17,46-57`, `machine/ts/spec/bmsx/memory_map.ts:23-33`; `machine/cpp/spec/bmsx/model.h:12-22,51-62`, `machine/cpp/spec/bmsx/memory_map.h:29-39`.

GCR-20 Defined per-unit limits: XFORM2 max vertices64; SAT2 max polygon vertices64; OVERLAP max polygon vertices64 and clip vertices128. Controller count is a full32 word and controller has no lower batch-count cap. One optional active job, not16 jobs:16 is register count. Sources: `machine/ts/machine/devices/geometry/contracts.ts:57,78,135-136`, `machine/ts/machine/devices/geometry/controller.ts:83-85,330-372`; `machine/cpp/machine/devices/geometry/contracts.h:65,86,143-144`, `machine/cpp/machine/devices/geometry/controller.h:66-69`, `machine/cpp/machine/devices/geometry/controller.cpp:225-265`.

GCR-21 Installed timing path: TimingState gets CPUHz and GEO units/s from MachineModelSpec; runtime refresh passes those to Machine.refreshDeviceTimings; that calls GEO.setTiming(cpuHz,geoWorkUnitsPerSec,nowCycles). setTiming preserves carry/available units while BUSY, clears them when not BUSY, and reschedules. Machine.advanceDevices accrues GEO cycles before advancing scheduler time; GEO device service dispatch calls GEO.onService at scheduler.nowCycles and returns zero extra cycles. Sources: `machine/ts/machine/runtime/timing/state.ts:23-29`, `machine/ts/machine/runtime/timing/config.ts:3-7`, `machine/ts/machine/machine.ts:122-140`, `machine/ts/machine/devices/geometry/controller.ts:152-176`; `machine/cpp/machine/runtime/timing/state.cpp:17-22`, `machine/cpp/machine/runtime/timing/config.cpp:7-12`, `machine/cpp/machine/machine.cpp:65-83`, `machine/cpp/machine/devices/geometry/controller.cpp:87-111`.

GCR-22 Work arithmetic: while BUSY and cycles>0, `numerator=U*cycles+carry`; wholeUnits=integer quotient numerator/H; nextCarry=numerator%H. New available units are capped to remaining records minus already available units; idle time banks no work. Fresh nonzero launch resets carry and units to0. Thus H/U=1323/640 CPU cycles per nominal work unit for installed model. Sources: `machine/ts/machine/scheduler/budget.ts:6-9`, `machine/ts/machine/devices/geometry/controller.ts:162-175,366-372`; `machine/cpp/machine/scheduler/budget.h:12-15`, `machine/cpp/machine/devices/geometry/controller.cpp:97-111,259-265`; installed constants GCR-19.

GCR-23 Service accounting is exactly one work unit per successful or failing outer processRecord invocation, independent of unit command, number of vertices, record byte size, broadphase/exact tests, clipping work, contact count, or memory bandwidth. Service loops while BUSY and available units remain; each iteration invokes selected unit once then decrements1. FULL_PASS processRecord can perform many pairs; do not label16,384,000 units/s as16,384,000 vertices/s or full-pass pairs/s. Per-unit algorithm facts establish those payload loops separately. Sources: `machine/ts/machine/devices/geometry/controller.ts:190-234`, `machine/cpp/machine/devices/geometry/controller.cpp:179-222`.

GCR-24 Deadline: service target=min(remainingRecords,1). If already available>=target, schedule at nowCycles. Otherwise schedule at `nowCycles+ceil(((target-available)*H-carry)/U)` with the shared integer formula (and shared helper returns1 if needed<=0). Not BUSY cancels GEO service. A fresh continuously accrued budget can fund N records after ceil(N*H/U) CPU cycles (N>0), before scheduler lateness, launch/CPU instruction/IRQ overhead, and fault/abort/rejection. Installed examples N=1→3;2→5;4→9;16→34;64→133;640→1323 cycles. These are calculated work-credit thresholds, not measured whole-routine completion promises. Sources: `machine/ts/machine/devices/geometry/controller.ts:59,375-387`, `machine/ts/machine/scheduler/budget.ts:12-18`; `machine/cpp/machine/devices/geometry/controller.cpp:14,286-297`, `machine/cpp/machine/scheduler/budget.h:18-20`; accrual GCR-22.

GCR-25 Scheduler integration: currentNowCycles is scheduler time outside a CPU slice, or sliceBase+(sliceBudget-CPU.instructionBudgetRemaining) within it. Timer due criterion deadline<=schedulerNowCycles. Re-scheduling/cancellation advances that device's timer generation; stale entries are ignored. GEO uses service kind1, SYSTEM kind6. This is emulated-cycle scheduling, not host wall-clock timing. Sources: `machine/ts/machine/scheduler/device.ts:4-11,52-56,95-115,175-182`; `machine/cpp/machine/scheduler/device.h:15-22`, `machine/cpp/machine/scheduler/device.cpp:33-37,58-78,137-144`.

GCR-26 Limits of extraction: controller/scheduler/model owners contain no per-vertex/pair-size/bandwidth cost terms, no setup-latency constant, no GEO command FIFO, no public GEO clock control word, and no declared physical electrical ratings. The software model's work-unit rate and captured32-bit registers above are authoritative for this edition; absence of physical ratings is a separate design decision, not a source mismatch to repair. Relevant complete controlling paths: `machine/ts/machine/devices/geometry/controller.ts:82-453`, `machine/ts/machine/scheduler/budget.ts:6-18`, `machine/ts/spec/bmsx/model.ts:27-57`; `machine/cpp/machine/devices/geometry/controller.h:21-75`, `machine/cpp/machine/devices/geometry/controller.cpp:38-361`, `machine/cpp/machine/scheduler/budget.h:12-20`, `machine/cpp/spec/bmsx/model.h:32-62`.

# GEO example source-language evidence

Editorial source-language slice, not hardware facts. The actual GEO register,
record and numerical contract comes from the separately frozen paired owners.
No architecture document or style PDF was read. Firmware and cartridge source
language are shared producers, not two independent mirrored runtime proofs.

**GBL01 — Typed ports and completion predicates.** Firmware programs actual
MMIO through scalar `*word` pointers, captures a BSS completion sequence before
the doorbell and waits in a sequence predicate containing `halt_until_irq`.
A handler advances the sequence. Sources:
`machine/bios/kernel/dma.lua:4–8,14–33`.

**GBL02 — Owned IRQ acknowledgement.** Firmware dispatch passes masked and full
flags to registered handlers and combines only handled bits for controller ACK.
The public direct-handler example can likewise acknowledge only the owned GEO
DONE/ERROR bits; their actual numbers come from GCR, not this source-language
precedent. Source: `machine/bios/kernel/interrupts.lua:3–16`.

**GBL03 — Authored typed operands, not a runtime register table.** Firmware has
named typed readonly arrays and a typed view over that data; it also declares
record types followed by typed readonly record arrays. Sources:
`machine/bios/math/sin.lua:1–3,34–46`;
`machine/bios/shell/commands.lua:61–78`.

**GBL04 — Existing direct GEO source pattern.** The actual collision library
uses typed shape/instance/pair/result/summary records, F32 coordinates, typed
views over the two contiguous programmable register runs, explicit source,
destination/count/parameter/stride writes followed by CMD, and separate DONE
and ERROR IRQ handlers. This proves the source-organization pattern only; the
chapter must not infer hardware semantics or expose these local helpers as
firmware exports. Sources:
`cartlib/collision/collision_2d.lua:20–94,366–407`.

The runnable example will retain buffers and observations in explicit BSS,
use named readonly inputs, program raw words directly and wait on actual
completion predicates. No local fixed-point/register encoding helper, generic
Lua register table, invented firmware export or extra runtime layer is needed.

**GBL05 — Current readonly initializer boundary.** The readonly primitive
producer accepts compile-time integer initializers for U8/U16/Word/U32, not F32
initializers. The example therefore stages its floating-point shape in BSS via
typed F32 stores, as the existing GEO library does, rather than adding a local
float encoder or changing the compiler. Source:
`toolchain/ts/lua/compiler.ts:3800–3818`;
`cartlib/collision/collision_2d.lua:117–125,148–165`.

# GEO shared IRQ-controller boundary supplement
