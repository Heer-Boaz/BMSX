# BIOS table library: paragraph assignments

Completion target: a programmer new to BMSX can choose and call every installed
table-library operation, preserve nil-bearing tuples, edit sequences, normalize
ranges, supply a comparator and understand partial effects without inspecting
firmware. This chapter does not establish an unpublished common Table-length
producer contract or complete the remaining BIOS/library/environment reference.

1. Root: installation, language Tables versus typed storage, API inventory and
   the shared maintained-length/read/write boundary. Define a length snapshot
   without inventing a universal populated-prefix formula.
2. Independent facts-only author: pack, unpack and concat; complete counts,
   omitted/nil arguments, positive/negative/zero/fractional range conversion,
   inherited reads, nil fragments, mutable dependencies and bounded resource
   cautions. Supply finished English prose and a fact map.
3. Independent facts-only author: insert, remove and sort; argument-count branch,
   mutation order, unusual positions, comparison protocol, prescan, partial
   effects and exact result counts. Supply finished English prose and a fact map.
4. Separate example author: complete ordinary BLua result and entry modules,
   assembly/manifest instructions, retained observations and independently
   observed ordinary diagnostics. Exercise default-length paths as well as
   explicit tuple counts; do not avoid the unresolved contract as a shortcut.
5. Nonauthors: check actual owners against every claim and the complete program;
   public-only newcomer reconstruction; individual-page review of the actual
   final draft PDF. Existing publisher only; no framework or validation layer.

Publication stop: the already reproduced generic SETT/rawset boundary-refill
length disagreement remains open. All six APIs can have their actual source
procedures documented, but default/relative ranges and post-mutation length
cannot be declared a complete common contract by naming an abstract L or by
passing one sequence example. Leave affected coverage open and this chapter a
draft. No runtime/compiler/BIOS repair is authorized by the documentation task.
