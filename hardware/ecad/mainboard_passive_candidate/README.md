# Passive INPUT and memory candidate

This separate project derives from the INPUT-and-memory candidate. The unused
J70 fan-supply connector and its independent V5 and GND branches are removed
from the schematic and PCB. No fan is part of the passive console design.
The preceding candidate and the original project remain unchanged.

The PCB remains unrouted and its zones unfilled. This project retains the
proposed INPUT and memory assignments; it does not establish ASIC logic,
electrical timing, complete assembly fit or thermal qualification.
